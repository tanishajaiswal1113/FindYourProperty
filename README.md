# FindYourProperty 🏡

FindYourProperty is a property listing web application that helps users
browse and search for properties based on their preferences.

## Features

- Add new property listings
- View property details
- Edit and delete properties
- Search properties by title and location
- Filter properties by budget, bedrooms, and property type
- Sort properties by price
- Save favourite properties

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- HTML, CSS, JavaScript

## Installation

1. Clone this repository.
2. Install dependencies:

   npm install

3. Create a `.env` file and configure your environment variables:

   MONGODB_URI=your_mongodb_connection_string
   SESSION_SECRET=your_session_secret

4. Start the application:

   node app.js

5. Open http://localhost:3000 in your browser.

## Purpose

This project was developed to practise full-stack web development,
database integration, CRUD operations, and search functionality.
